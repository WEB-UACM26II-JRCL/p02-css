conceptos fundamentales de maquetación web, selectores avanzadas y propiedades de estilo para dar formato a la interfaz HTML.🛠️ Selectores CSS Utilizados y su FunciónSelectorDescripción / Propósito.tituloSelector de clase: Selecciona el encabezado <h1> principal para centrarlo y darle tamaño.#tabla-preciosSelector de ID: Aplica el ancho, borde general y colapso de bordes a la tabla de precios.#tabla-precios thSelector descendente: Aplica estilos de fondo, color de texto y padding a las celdas de encabezado de la tabla.#tabla-precios tdSelector descendente: Define un borde inferior y espaciado interno para las celdas de datos de la tabla.#tabla-precios tbody tr:nth-child(even)Pseudo-clase :nth-child: Selecciona automáticamente las filas pares de la tabla para darles un fondo alternado.#tabla-precios tbody tr:hoverPseudo-clase :hover: Aplica un cambio de color de fondo a la fila sobre la cual el usuario pasa el cursor..contenedor-alertasSelector de clase: Controla el margen, relleno interno y color de fondo de la caja contenedora de alertas..contenedor-alertas > pSelector de hijo directo (>): Selecciona únicamente los párrafos que son hijos inmediatos de la alerta, ignorando los párrafos anidados (como el que está dentro de <section>).a + aCombinador de hermano adyacente (+): Selecciona y cambia el color de los enlaces (<a>) que están colocados inmediatamente después de otro enlace.a:hoverPseudo-clase :hover: Aplica negrita y cambio de color cuando el cursor se posiciona sobre cualquier enlace.a[href*="servicios" i]Selector de atributo (*=, i): Selecciona cualquier enlace cuya URL contenga la palabra "servicios" (sin importar mayúsculas o minúsculas) para aplicarle un fondo y color especial.🎨 Propiedades CSS Aplicadastext-align: Define la alineación horizontal del texto (ej. center).color: Cambia el color de la tipografía (usando nombres de color como darkblue, green, black o valores en inglés).font-size: Establece el tamaño de letra (ej. 32px).width: Controla el ancho de los elementos (ej. 80%).border: Define el borde completo de un elemento especificando grosor, estilo y color (1px solid black).border-bottom: Aplica borde únicamente a la parte inferior de una celda o contenedor.border-collapse: Elimina el espacio doble entre bordes de celdas adyacentes en las tablas (collapse).background-color: Define el color de fondo de contenedores, filas, celdas y enlaces.padding: Genera espaciado interno entre el contenido de un elemento y su borde.margin: Controla el margen y espacio exterior que separa un elemento de sus vecinos.font-weight: Modifica el grosor de la fuente (ej. bold para negrita).⚠️ Correcciones Sugeridas en el Código CSSDurante la realización del examen se identificaron y corrigieron pequeños detalles sintácticos para asegurar la validación correcta:Borde de la tabla: Se corrigió la sintaxis de border: 1px solid black #ccc; a border: 1px solid #ccc; para evitar valores redundantes de color.Color de texto en los encabezados th: Se corrigió color: #white; a color: white; (o #ffffff), eliminando el símbolo # de los nombres de color en inglés.Estructura semántica de la tabla: Se recomienda envolver la fila de encabezados en la etiqueta <thead> y el resto de las filas en <tbody> para asegurar el funcionamiento óptimo de los selectores :nth-child y :hover.
